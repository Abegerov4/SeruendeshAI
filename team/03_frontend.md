# Роль 3 — Frontend

**Ветка:** `feature/frontend`  **Папка:** `frontend/`  **Merge:** третий

Ты делаешь то, что жюри увидит первым. Это 4-й критерий оценки (UX и понятность демо). Задача: чтобы любой за 10 секунд понял, как получить рекомендацию, и сразу видел, **почему** система советует это место и **какие данные** она использовала.

Контракт API описан в [README.md](README.md#33-http-api-его-отдаёт-backend-вызывают-frontend-и-qa). Начинай на моках, бэкенд для старта не нужен.

---

## Стек
React + Vite (+ TypeScript по желанию), Leaflet / react-leaflet с тайлами OpenStreetMap, без тяжёлых UI-фреймворков (хватит Tailwind или простого CSS).

## Структура

```text
frontend/
  src/
    api.ts               # fetch POST /api/recommend; VITE_API_URL из .env; флаг VITE_USE_MOCK
    mocks/recommend.json # 3 ответа по контракту (прогулка, ребёнок, турист)
    components/
      ChatPanel.tsx       # ввод запроса + история
      QuickScenarios.tsx  # кнопки-сценарии одним кликом
      Filters.tsx         # время (30/60/120 мин), пешком/авто, с ребёнком, турист, доступность, язык
      RecCard.tsx         # карточка рекомендации
      MapView.tsx         # карта: пользователь (круг ~100 м), POI, маршрут
      UsedContext.tsx     # «Что я учёл»: локация, радиус, фильтры, время
      PrivacyBanner.tsx   # как мы обращаемся с геолокацией
    App.tsx
  .env.example            # VITE_API_URL=http://localhost:8000, VITE_USE_MOCK=1
```

## Задачи

### Этап 1 — на моках (до CP2)
- [ ] Каркас: слева чат и фильтры, справа карта (на мобильном карта под чатом)
- [ ] **Быстрые сценарии** (кнопки), которые подставляют текст запроса:
  «Я возле Mega Silk Way, 30–60 мин погулять» · «Тихое место с кофе и розеткой» · «С ребёнком: площадка или интерактивный музей» · «Турист, 2 часа до вылета» · «Необычное ночью»
- [ ] **Карточка рекомендации** (всё из контракта):
  - название, категория-иконка, `distance_m` + `travel_min` («650 м · 8 мин пешком»)
  - **«Почему:»** `why`
  - **«Что делать:»** `what_to_do`, время на месте `visit_min` («30–45 мин»)
  - бейдж режима работы: открыто (зелёный) / закрыто / «часы неизвестны» (серый) + уверенность
  - бейдж источника: «📍 Данные POI» или «✨ Идея ИИ» (`source: generated`). Это требование организаторов
  - ссылка «Источник» (`source_url`), рейтинг, если не `null`
- [ ] Клик по карточке подсвечивает точку на карте и наоборот
- [ ] Блок **«Что я учёл»** (`used_context`): «Локация: ~ район Mega Silk Way (округлено) · Радиус 1,5 км · 60 мин · пешком · фильтры: парк». Жюри прямо требует, чтобы система ясно показывала, какие данные использует
- [ ] `notes` и `disclaimer` показываем мелким текстом под выдачей

### Этап 2 — геолокация и приватность (критерий 6)
- [ ] Кнопка «📍 Моё местоположение», `navigator.geolocation` только по клику, не автоматически
- [ ] **Округлять до 3 знаков (~100 м) ДО отправки** на сервер: `Math.round(lat*1000)/1000`
- [ ] Альтернатива без GPS: поле «Я возле…» (ориентир) или клик по карте. В демо можно выбрать «смоделированную локацию» из списка: ЭКСПО, Байтерек, Mega Silk Way, Хан Шатыр, аэропорт
- [ ] Ничего не хранить в `localStorage`, кроме выбранного языка/фильтров (координаты не сохраняем)
- [ ] `PrivacyBanner`: «Мы используем приблизительную локацию (~100 м) только для этого запроса и не храним её»

### Этап 3 — подключение к API и полировка (CP2 → CP3)
- [ ] `VITE_USE_MOCK=0`, чтобы ходить в реальный `/api/recommend`; лоадер «Подбираю места…», обработка ошибок и пустой выдачи
- [ ] **Мини-маршрут:** если `route` не `null`, рисуем полилинию 1 → 2 → 3 с нумерацией и пишем «≈ 70 мин всего»
- [ ] Языки RU / KK / EN (переключатель передаётся в `lang`; минимальные переводы интерфейса)
- [ ] Адаптив под мобильный (демо могут смотреть с телефона)
- [ ] Сборка: `npm run build`; (опц.) деплой на Vercel/Netlify/Firebase Hosting, чтобы жюри могли потыкать сами

## Подсказки
- Тексты карточки короткие: организаторы ценят «короткие конкретные рекомендации больше длинных рассуждений»
- Пример выдачи из ТЗ: «Музей… (300 м, 5 мин пешком). Почему: … план действий: 40–60 мин…». Карточка должна читаться так же
- Внешние картинки и ссылки из ответа ИИ не рендерим без проверки домена ([ai_security.md](../ai_security.md) §8)

## Что ты получаешь / отдаёшь
- **Получаешь** от Backend: `POST /api/recommend` по контракту (до этого используешь моки)
- **Отдаёшь** QA: запускаемый UI (`npm i && npm run dev`) для записи демо-видео и скриншотов презентации
