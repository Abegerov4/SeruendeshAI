## Из аудита Аслана — что исправлено в продукте
Исправления перенесены трёхсторонним слиянием: общая база — `4e0b503`, «наша» и «его» стороны сведены пофайлово. Среди них:
- **B01.** Лимиты запросов считаются атомарно в SQL по адресу собеседника; поддельный `X-Forwarded-For` их не обходит (то же исправлено в MCP).
- **B02–B05.**
  - Удаление аккаунта каскадно чистит всё связанное.
  - Сброс пароля одноразовый и отзывает остальные ссылки и сессии.
  - Сессии хранятся в БД, logout их отзывает.
  - Сохранённая карточка ограничена схемой и размером.
- **B06–B10.** Точное время в ключах кэша. Визит целиком укладывается в часы работы, включая переход через полночь. Подходы к узлам графа учитываются в маршруте.
- **B11.** У фото размер проверяется до чтения тела, чтение ограничено, декодирование идёт вне event loop и не больше двух одновременно.
- **B13.** Бот удаляет локацию по таймеру через 30 минут, даже если пользователь больше не пишет.
- **M02–M04.**
  - Маршрут — единственный источник длительностей.
  - Неполный ответ модели уходит в fallback без HTTP 500.
  - Явно названная цель проходит те же фильтры безопасности.
- **I07–I08.** Оценка суммирует дорогу и визиты; любой провал даёт ненулевой код возврата.

## Где решения отличаются от ветки `big-data` (сознательно)
- **Тексты карточек.** Аслан заменил тексты модели шаблонами (M01). Мы оставили тексты модели, но валидатор вырезает предложения с неподтверждёнными удобствами: Wi-Fi, розетки, детская комната, веранда, парковка, «бесплатно», «без ступеней», выставки. Тест Аслана на это проходит.
- **«2 часа до вылета».** При неизвестном типе рейса время считается свободным до выезда в аэропорт, и ответ прямо об этом говорит. Для «внутренний» и «международный» действуют запасы Аслана: 120 и 180 мин.
- **Источник данных.** По умолчанию API работает на снимке `backend/pipeline`: фото, отели, CityPass, описания на языке ответа. Канонический каталог Аслана включается флагом `DATA_SNAPSHOT_MODE=canonical`, и его тесты проходят в этом режиме.
- **Карантины разведены.** У конвейера API файл `data/quarantine_pipeline.json`, у каталога команды — `data/quarantine.json`.
- **`/api/auth/me` для гостя** отвечает `200 {"user": null}`: так в браузере нет ошибки 401. Отозванная сессия тоже получает гостевой ответ.
