## Контроль перед экспортом

- Подставить реальные результаты только из текущего `eval/runs/local/report.json` и `results.md`; не использовать учебные проценты или целевые значения как измеренные.
- Карта и карточки должны показывать один request_id/набор мест. Прогонить два быстрых запроса, проверив, что старый ответ не заменяет новый.
- Видны «почему», «что делать», дорога, визит, источник, неизвестные часы и «Что я учёл». Если маршрут отсутствует, не дорисовывать его в монтаже как результат API.
- Проверить чтение мобильной версии с открытой клавиатурой, RU/KK/EN и отсутствие персональных данных в кадре.
- При недоступности API/LLM показать фактическое состояние с честной пометкой; не склеивать счастливые ответы в ложный непрерывный live-сеанс.
- После реального экспорта проверить длительность 2–3 минуты, звук, текст, начало/конец; загрузку и доступ по ссылке проверить из отдельного окна. До этого статус видео — NOT CREATED / NOT PUBLISHED.
