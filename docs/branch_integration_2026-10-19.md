## Исправления совместимости

1. Устранены две прежние ошибки импорта `app` в общем pytest; пакеты, тесты и команды запуска имеют отдельный namespace.
2. Сохранённые карточки после загрузки с сервера восстанавливают иконки и массивы; React больше не падает на отсутствующем icon.
3. Избранное отделено по аккаунтам; logout и запоздалые ответы не переносят карточки другому пользователю.
4. PUT/DELETE избранного принимают канонические OSM ID со слешем, например `osm:node/13667384701`; раньше URL после декодирования не совпадал с маршрутом.
5. Неоднозначные `Coffee Boom`, `Додо Пицца` и подобные сети не подменяются более коротким именем или случайным филиалом при fuzzy-поиске. Уточнённые филиалы и склонения курируемых ориентиров продолжают работать.
6. События привязаны к новым canonical ID через однозначные исходные aliases.

Сценарий теста отеля уточнён с неоднозначного `Hilton` до имеющегося в источнике `Hilton Astana`. Его проверки не ослаблялись; короткое имя не назначалось произвольному отелю.

## Что остаётся проблемой

- **«Два часа до вылета» не готово для надёжного демо.** Текущий сервер трактует это как время прибытия в аэропорт и оставляет 30 минут, отдельно предлагая пользователю учесть ещё 1,5 часа регистрации. Запрос явно о вылете требует применения этого запаса в расчёте, а не только предупреждения. Политика дедлайна в этой интеграции не менялась.
- Настоящая LLM, dense-поиск, live-погода и email не тестировались; локальные ответы — правила и шаблоны на реальных данных. Красный LLM-readiness тест сохранён без ослабления.
- Статус `unknown` у часов остаётся неизвестностью. Успех схемы/HTTP не означает подтверждение всех фактов и полезности рекомендации.
- Исторические отчёты Ayat/QA относятся к их прежним снимкам; их метрики не присваиваются объединённой версии.

Все шесть локальных branch heads, основной checkout Aslan и исходные Data сохранены. Изменения остаются незакоммиченными только в `big-data`; push не выполнялся.
