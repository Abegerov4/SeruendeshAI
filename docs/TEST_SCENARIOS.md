# Тестовые сценарии и ограничения

Сценарии лежат в [`backend/eval/scenarios.yaml`](../backend/eval/scenarios.yaml). Харнесс [`backend/eval/run_eval.py`](../backend/eval/run_eval.py) отправляет каждый сценарий в API и автоматически проверяет жёсткие ограничения. По флагу `--judge` LLM-судья дополнительно ставит оценки 1–5. Время и погода в сценариях зафиксированы, поэтому результаты воспроизводимы.

```bash
cd backend
uv run python eval/run_eval.py --no-llm     # без ключа: шаблонный режим
uv run python eval/run_eval.py --judge      # LLM + LLM-as-judge → docs/EVAL_RESULTS.md
```

Свежие результаты: [EVAL_RESULTS.md](EVAL_RESULTS.md).

## Автоматические проверки (для каждого сценария)
| Код | Проверка |
|---|---|
| C1 | Ответ валиден по схеме `RecommendResponse` (контракт §3.3 + расширения) |
| C2 | 1–3 места (или 0, если так и ожидается) |
| C3 | Все `poi_id` существуют в базе: LLM не выдумал место |
| C4 | `travel_min` каждого места ≤ бюджета; маршрут ≤ бюджета |
| C5 | Категории из разрешённого набора (если задан) |
| C6 | Метки источника есть; у «идей ИИ» нет ссылок и статуса часов |
| C7 | Язык ответа совпадает с ожидаемым |
| C8 | В текстах LLM нет времени «HH:MM» и фраз «открыто сейчас» |
| C9 | Координаты в `used_context` округлены до 3 знаков |
| C10 | Правила безопасности: дети, ночь, мороз, доступность |
| C11 | Ни одного места, закрытого к моменту прихода |
| C12 | Задержка < 8 с |
| S | Специфика сценария: источник локации, «выйти до», нужные `notes`, язык, режим, отсутствие утечки промпта |

Плюс 698 unit- и контрактных тестов в `backend/tests/` (в CI всего ~1 500 проверок, включая 30 тестов фронтенда и 31 браузерный). Среди них:
- часы работы, включая переносы праздников и «закроется до конца визита»;
- разбор бюджета времени на RU/KK/EN;
- определение языка;
- валидатор LLM-текста;
- категории OSM;
- учёт реки в расстояниях;
- контракт API, округление координат, отсутствие баров для детей, режим такси на морозе, ответ без локации;
- аккаунты, строгие типы, маскирование ПД, старт и цель в одной фразе, отели как старт;
- оффтоп, режим по фото, MCP-коннектор, учёт токенов и стоимости;
- строгое сопоставление названий, фильтр фото, локализованные описания.

## Ограничения

**Данные**
- Часы работы есть примерно у 20% мест (OSM). У остальных честно пишем «часы неизвестны — уточните» и не утверждаем, что открыто.
- В открытых данных по Астане нет рейтингов, поэтому `rating` всегда `null`. Популярность оценивается по Wikipedia/Wikidata и полноте данных.
- Розетки, «тишина» и Wi-Fi размечены редко, система предупреждает об этом в `notes`.
- Живые описания (Wikipedia) есть только у ~40 крупных достопримечательностей. У остальных краткое описание собрано из фактов: категория, кухня, удобства, известный ориентир рядом и адрес на языке ответа.
- Данные OSM и Wikipedia редактируются пользователями и могут устаревать. Снимок обновляется раз в неделю, есть кнопка «сообщить об ошибке».

**Расчёты**
- Пешеходный граф покрывает центр (Левый и Правый берег, ЭКСПО, НУ). Для окраин и аэропорта используется формула «прямая × коэффициент» с поправкой на Есиль, в `notes` об этом есть пометка.
- Время на машине и общественном транспорте — эвристика без пробок и расписаний в реальном времени.
- Праздники РК учитываются, но в такие дни часы работы мест могут отличаться от указанных в OSM.

**LLM**
- Тексты «почему» и «что делать» иногда общие, особенно для мест без описания. Факты в них ограничены валидатором, а стиль зависит от модели.
- LLM-судья строг и нестабилен: оценки 1–5 колеблются от прогона к прогону на ±0.3. Поэтому главная метрика — жёсткие проверки C1–C12.
- Казахский: если модель ответила по-русски, система переключается на шаблон на казахском.
- Время ответа ~3–4 с на 2 вызова LLM. Без LLM ответ занимает < 0.2 с.

**Продукт**
- События (Ticketon/Sxodim) собираются отдельной командой пайплайна и зависят от доступности сайтов.
- Групповой режим пока учитывает только тип досуга, без голосования участников.
- Аккаунты хранят только имя, email, хэш пароля и избранное. Истории запросов и локаций нет: так задумано ради приватности, поэтому персонализации по прошлым прогулкам тоже нет.
- Настоящие фото есть только у ~27 известных мест (Wikimedia Commons). У остальных обложка категории.
