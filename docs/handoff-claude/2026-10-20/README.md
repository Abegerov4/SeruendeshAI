# Передача доработок SeruendeshAI Клоду

От Codex для Клода, 20 октября 2026. Ветка `ayat`, исходный коммит `3958f18`. Здесь описаны изменения после аудита проекта, проверка и следующая очередь работ. Пользователь попросил коммит в `ayat`; публикация на сервер не входит в этот этап.

## Что изменено

### Аккаунты и сохранения

- `frontend/src/main.jsx`: Workspace пересоздаётся при смене ID аккаунта. Старые сохранения не остаются после выхода и не отправляются в новый аккаунт. Ответы загрузки и незавершённые записи отменяются при размонтировании.
- Автоматическое объединение гостевых и пользовательских сохранений убрано. Гостевые места временные; при входе отображается список аккаунта. Если нужен импорт гостевых мест, сделать отдельное явное действие, не возвращать прежний безусловный merge.
- Запись избранного оптимистическая, но при ошибке откатывается. Есть повтор и отдельное сообщение внутри открытого диалога: глобальное уведомление недоступно под native dialog.
- `frontend/src/auth.js` и `backend/app/auth.py`: синхронизирован формат сохранения. Теперь сохраняются iconKey, photo с автором/лицензией/ссылкой, описание, сайт, телефон, Instagram, кухня и состояние часов. Новые ссылки проверяются на HTTP(S), размер снимка по-прежнему ограничен 16 KiB.
- Старые снимки продолжают открываться с иконкой по категории. Недостающие старые фото/описания автоматически не восстанавливаются. На странице сохранений есть предупреждение об устаревании данных.

### Первый запуск и мобильный интерфейс

- `Explore.jsx`: при первом открытии нет автоматического поиска без локации и запроса GPS. Показан выбор точки старта: геолокация по нажатию, Байтерек / Mega / EXPO, ввод адреса или ориентира.
- Ссылки с `q` и `from` продолжают запускать сценарии. Написанный адрес передаётся в текст запроса; поиск и разрешение неоднозначности остаются на сервере.
- После ответа показан распознанный старт. Кнопка «Все места · 0» больше не перекрывает пустое состояние карты.
- Новый адресный ввод учитывается при открытии мобильной клавиатуры: нижний бар скрывается, поле адреса остаётся доступным.
- `RouteOverview.jsx`: без общего маршрута время считается для выбранного места, а список явно назван отдельными вариантами.
- Новые тексты добавлены на RU/KK/EN. Стили сгруппированы в `usability.css`.

### Доверие в карточках

- `wheelchair=no` больше не описывается как доказательство наличия ступеней. Формулировки относятся к доступности на коляске по данным источника.
- Фото с сайта заведения в блоке доверия больше не подписывается как Wikimedia Commons.

### Бэкенд рекомендаций

- `flight_unknown_buffer_min` по умолчанию 180 вместо 0. Запрос «2 часа до вылета» больше не трактуется как два часа свободной прогулки. Для внутренних рейсов осталось 120, международных — 180; дорожный резерв 15 минут учитывается отдельно.
- При нулевом бюджете перед вылетом ответ предлагает ехать в аэропорт и уточнить рейс. Ожидание S4 и тест нормальных запросов обновлены: полезный ответ может быть без рекомендаций.
- Если `route_out` отсутствует, `why` и `what_to_do` для POI формируются существующими шаблонами конкретного места. LLM продолжает выбирать места и длительность в допустимом диапазоне, но её произвольный текст не связывает альтернативы в несогласованную прогулку. Summary собирается кодом и предлагает выбрать одно место.
- Это осознанный компромисс: текст альтернатив менее разнообразный. Следующее улучшение — фактически подтверждённые индивидуальные действия в рамках одного места, с оценкой качества перед возвратом свободной генерации.
- Настоящие маршруты сохраняют последовательность и генерацию объяснений; новый фикс не заменяет полный аудит их текстов.
