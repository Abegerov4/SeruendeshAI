# SeruendeshAI — Secret Path

React + Vite интерфейс городского помощника. Молочный фон, лесной зелёный, лаймовый акцент; главный экран с фотобаннером, чатом, фотокарточками, картой и избранным. Рекомендации, аккаунты и избранное подключены к API.

## Запуск

```bash
# Из корня: установить Python-зависимости проекта и запустить совместимый API Ayat
.venv/bin/python -m uvicorn ayat_backend.app.main:app --host 127.0.0.1 --port 8001

# В другом терминале
cd frontend
npm ci --no-audit --no-fund
VITE_PROXY_TARGET=http://127.0.0.1:8001 npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

http://127.0.0.1:5173 — Vite с live reload. Все `/api` запросы идут через прокси на API; используйте один и тот же хост в браузере, чтобы сохранялась сессия.

```bash
npm run build
VITE_PROXY_TARGET=http://127.0.0.1:8001 npm run preview -- --host 127.0.0.1
```

Для локальной проверки без внешних сервисов задайте API переменные `LLM_ENABLED=false EMBED_MODEL=off WEATHER_ENABLED=false`. Аккаунты используют локальный SQLite, если `DATABASE_URL` не задан; задайте `SECRET_KEY`, чтобы сессии переживали перезапуск. Письма восстановления требуют настроенного SMTP; без него форма честно сообщает о недоступности почты. Не подключайте рабочие БД или SMTP для локальных тестов.

## Страницы

- `/` — чат, подборка, карта и предпочтения.
- `/saved` — избранные места и пустое состояние.
- `/login` — вход по email и паролю.
- `/register` — регистрация: имя, email, пароль.
- `/forgot-password` — запрос восстановления доступа; `/reset-password?token=...` — новый пароль.
- Остальные пути показывают страницу 404.

Для статического хостинга нужен SPA fallback на `index.html`, чтобы прямые ссылки и обновления страниц работали. Vite поддерживает его локально.

## Интерфейс

- Компактный фотобаннер с переходом и фокусом в чат.
- Чат: история последних 20 сообщений, быстрые сценарии, индикатор ответа, Enter для отправки, Shift+Enter для новой строки, сброс диалога. Выбор сценария отменяет ожидающий предыдущий ответ.
- Карточки: фотографии, «почему», действие на месте, расстояние, время, избранное, подробности и источники. AI-визуализация Байтерека помечена; фото кофе не изображает конкретное заведение.
- Карта: Leaflet + OpenStreetMap, фирменные маркеры, выбранное место, приближение и мини-маршрут по улицам из ответа API.
- На ширине до 900 px: вкладки «Чат / Места / Карта», контекстная нижняя панель, переход с карточки на выбранную точку, клавиатурная навигация по вкладкам стрелками и Home/End.
- Формы: проверка полей, сообщения ошибок, показ/скрытие пароля, переходы между входом, регистрацией, восстановлением и гостевым просмотром.
- Анимации появления, наведения и выбора; поддерживается `prefers-reduced-motion`.

## Подключение к API (живые данные)

Фронт работает с расширенным RAG-бэкендом из `ayat_backend/` (контракт: [`docs/API.md`](../docs/API.md)). Основной API из `backend/` сохраняет более узкий контракт и сам по себе не поддерживает аккаунты, уточнения и геометрию маршрутов этого интерфейса.

- `src/api.js`:
  - `POST /api/recommend` строит запрос: координаты округлены до 3 знаков, ориентир, профиль, уточнения `refine`;
  - адаптирует ответ к карточкам: «почему», «что делать», часы с уверенностью, источники, «выйти до», события.
- Dev: `VITE_PROXY_TARGET` задаёт адрес API в `vite.config.js` (по умолчанию `http://localhost:8000`; команда выше использует Ayat на порту 8001). `VITE_API_URL` задаёт отдельный адрес API при сборке; для cookie-сессий предпочтителен прокси на том же origin.
- После `npm run build` API Ayat раздаёт `frontend/dist/` на том же домене; прямые ссылки на страницы поддерживаются через SPA fallback.
- Карта на Leaflet и тайлах OpenStreetMap: остановки, «Вы здесь» (округлено) и маршрут по графу улиц из ответа API.
- Уточнения «Ближе / Без кофе / В помещении» пересчитывают подборку на сервере. Блок «Что изменилось» показывает разницу с прошлым вариантом и позволяет вернуться к нему.
- «Моё местоположение» запрашивает геолокацию только по выбору пользователя. Координаты округляются до ~100 м и нигде не сохраняются.
- Фото в карточках — иллюстрации категорий и подписаны так.
- Аккаунты используют httpOnly cookie. Избранное гостя хранится в памяти вкладки, переносится при входе и затем сохраняется на сервере. Выход очищает карточки аккаунта; запоздавший ответ прежней сессии не меняет новый список.
- Тесты: `npm test` (node:test) проверяет округление координат, сборку запроса, адаптер, разницу планов, восстановление настоящих React-карточек из сохранённых снимков и изоляцию аккаунтов при асинхронной загрузке.

## Структура

- `src/main.jsx` — корневые страницы; `src/auth.js`, `src/saved-session.js` — сессия и избранное.
- `src/navigation.jsx` — навигация через History API, обычные ссылки и back/forward.
- `src/pages/Explore.jsx`, `Auth.jsx`, `Saved.jsx` — страницы.
- `src/components/Chat.jsx`, `MapView.jsx`, `PlaceCard.jsx`, `Layout.jsx` — компоненты.
- `src/design.css` — активная адаптивная дизайн-система. Старые `style.css` и `brand.css` не подключены.
- `public/brand/secret-path.svg` — знак.
- `public/images/photo-sources.txt` — происхождение фото, статус референсов.

## Проверка

Production build проходит. В Chromium проверены маршруты, валидация входа/регистрации/восстановления, показ пароля, избранное, чат и сценарии, Enter / Shift+Enter, мобильные вкладки и выбранная точка карты. На ширинах 320 и 390 px нет горизонтального переполнения; reduced motion отключает анимации; ошибок JavaScript не обнаружено.

## Серу и визуальные истории

- Маскот — степная птичка Серу с зелёной сумкой. `src/components/Mascot.jsx` использует прозрачный WebP из `public/mascot/`.
- `src/components/MoodStories.jsx`: три фотографические истории настроения. Клик выбирает сценарий, открывает чат и отправляет соответствующий запрос. Это AI-иллюстрации, не карточки реальных заведений.
- Серу появляется в первом экране, аватаре чата, индикаторе ответа, пустом избранном и на страницах авторизации. «Удиви меня» отправляет один из быстрых сценариев в API.
- `src/life.css` дополняет основную дизайн-систему: фотокарточки, мягкий фон, подсказки, приветственная анимация и hover-состояния. Системный reduced motion отключает движение.
- Фотосцены и маскот созданы встроенным image_gen. WebP — оптимизированные копии; оригиналы сохранены. Новый вид сохранён в `screenshots/seru-desktop.png` и `screenshots/seru-*-mobile.png`.
- Проверены сценарии историй, возврат в чат с карты, сброс диалога, случайный сценарий, ширины 320/390/768 px и reduced motion.
