# SeruendeshAI — Secret Path

Интерфейс SeruendeshAI на React + Vite: молочный фон, лесной зелёный, лаймовый акцент; главный экран с баннером, чатом с Серу, карточками мест, картой и избранным. Все данные живые: интерфейс работает с RAG-бэкендом из `backend/` и настоящими аккаунтами. Демо: https://seruendesh.site

## Запуск

```bash
cd frontend
npm install
npm run dev -- --port 5173 --strictPort
```

http://localhost:5173 — Vite с live reload.

```bash
npm run build
npm run preview
```

## Страницы

- `/` — чат, подборка, карта и предпочтения.
- `/saved` — избранные места и пустое состояние.
- `/login` — вход по email и паролю.
- `/register` — регистрация: имя, email, пароль.
- `/forgot-password` — восстановление доступа (ссылка скрыта, если на сервере не настроена почта).
- Остальные пути показывают страницу 404.

Для статического хостинга нужен SPA fallback на `index.html`, чтобы прямые ссылки и обновления страниц работали. Vite поддерживает его локально.

## Интерфейс

- Компактный фотобаннер с переходом и фокусом в чат.
- Чат: история последних 20 сообщений, быстрые сценарии, индикатор ответа, Enter для отправки, Shift+Enter для новой строки, сброс диалога. Выбор сценария отменяет ожидающий предыдущий демо-ответ.
- Карточки: настоящее фото места из Wikimedia Commons с автором и лицензией (у известных мест), иначе абстрактная обложка категории, а не чужое фото. Дальше «почему», «что делать», расстояние и время, статус часов цветом, быстрые действия: маршрут в 2GIS, сайт, звонок.
- Подробности места: фото или обложка, кнопки «Маршрут / Позвонить / Сайт / Instagram / Поделиться», факты (дорога, время на месте, часы, адрес, кухня), описание со ссылкой на Википедию, источники данных.
- Карта: Leaflet + OpenStreetMap, фирменные маркеры, выбранное место, приближение и мини-маршрут по улицам из ответа API.
- На ширине до 900 px чат открывается на весь экран, как мессенджер. Поле ввода закреплено над клавиатурой (`visualViewport`), шрифт 16 px, чтобы iOS не зумил страницу. Системная кнопка «Назад» сворачивает чат. На странице остаётся компактный вход «Спроси Серу» с настроениями, после прокрутки появляется плавающая кнопка. Вкладки «Места / Карта» переключают результаты.
- Формы: проверка полей, сообщения ошибок, показ/скрытие пароля, переходы между входом, регистрацией, восстановлением и гостевым просмотром.
- Анимации появления, наведения и выбора; поддерживается `prefers-reduced-motion`.

## Подключение к API (живые данные)

Фронт работает с RAG-бэкендом из `backend/` (контракт: [`docs/API.md`](../docs/API.md)).

- `src/api.js`:
  - `POST /api/recommend` строит запрос: координаты округлены до 3 знаков, ориентир, профиль, уточнения `refine`;
  - адаптирует ответ к карточкам: «почему», «что делать», часы с уверенностью, источники, «выйти до», события.
- Dev: `npm run dev` проксирует `/api` на `http://localhost:8000` (`vite.config.js`). Другой адрес задаётся через `VITE_PROXY_TARGET` или `VITE_API_URL`.
- Прод: FastAPI раздаёт `dist/` на том же домене, без CORS (корневой `Dockerfile`, деплой в Railway из ветки `ayat`).
- Карта на Leaflet и тайлах OpenStreetMap: остановки, «Вы здесь» (округлено) и маршрут по графу улиц из ответа API.
- Уточнения «Ближе / Без кофе / В помещении» пересчитывают подборку на сервере. Блок «Что изменилось» показывает разницу с прошлым вариантом и позволяет вернуться к нему.
- «Моё местоположение» запрашивает геолокацию только по выбору пользователя. Координаты округляются до ~100 м и нигде не сохраняются.
- Фото в карточках: Wikimedia Commons с автором и лицензией или обложка категории с подписью «не фото этого места».
- Аккаунты настоящие (`src/auth.js`): httpOnly-сессия, избранное хранится на сервере, гость сохраняет места до перезагрузки, а при входе они переносятся в аккаунт.
- Тесты: `npm test` (node:test) проверяет округление координат, сборку запроса, адаптер, разницу планов.

## Структура

- `src/main.jsx` — корневое состояние и страницы.
- `src/navigation.jsx` — навигация через History API, обычные ссылки и back/forward.
- `src/pages/Explore.jsx`, `Auth.jsx`, `Saved.jsx` — страницы.
- `src/components/Chat.jsx`, `MapView.jsx`, `PlaceCard.jsx`, `Layout.jsx` — компоненты.
- `src/design.css` — активная адаптивная дизайн-система. `src/polish.css` подключается последним: фото и обложки, читаемые размеры шрифтов, полноэкранный чат на телефоне. Старые `style.css` и `brand.css` не подключены.
- `src/components/PlaceVisual.jsx` — фото с атрибуцией или обложка категории.
- `public/brand/secret-path.svg` — знак; оригинал и SVG-адаптация в `../brand/logo/`.
- `public/images/photo-sources.txt` — происхождение фото, статус референсов.

## Проверка

Production build проходит. В Chromium проверены маршруты, валидация входа/регистрации/восстановления, показ пароля, избранное, чат и сценарии, Enter / Shift+Enter, мобильные вкладки и выбранная точка карты. На ширинах 320 и 390 px нет горизонтального переполнения; reduced motion отключает анимации; ошибок JavaScript не обнаружено.

## Серу и визуальные истории

- Новый маскот — степная птичка Серу с зелёной сумкой. `src/components/Mascot.jsx` использует прозрачный WebP; оригинал PNG и промпты лежат в `../brand/mascot/`.
- `src/components/MoodStories.jsx`: три фотографические истории настроения. Клик выбирает сценарий, открывает чат и отправляет соответствующий запрос. Это AI-иллюстрации, не карточки реальных заведений.
- Серу появляется в первом экране, аватаре чата, индикаторе ответа, пустом избранном и на страницах авторизации. «Удиви меня» выбирает один из демонстрационных сценариев.
- `src/life.css` дополняет основную дизайн-систему: фотокарточки, мягкий фон, подсказки, приветственная анимация и hover-состояния. Системный reduced motion отключает движение.
- Фотосцены и маскот созданы встроенным image_gen. WebP — оптимизированные копии; оригиналы сохранены. Новый вид сохранён в `screenshots/seru-desktop.png` и `screenshots/seru-*-mobile.png`.
- Проверены сценарии историй, возврат в чат с карты, сброс диалога, случайный сценарий, ширины 320/390/768 px и reduced motion.
