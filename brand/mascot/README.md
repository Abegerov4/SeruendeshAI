# Серу — маскот SeruendeshAI

Маленькая степная птичка с зелёной сумкой, дружелюбный городской спутник.

- `seru-wave.png` — исходный PNG с прозрачным фоном.
- `generation-prompts.json` — точные промпты маскота и двух фотографических сцен, созданных встроенным image_gen.
- Версия для сайта: `frontend/public/mascot/seru-wave.webp`.

Логотип Secret Path остаётся основным знаком бренда. Серу используется как персонаж в чате, приветствии, пустых состояниях и авторизации.
