# Telegram-бот Серу

**В продакшене бот работает внутри сайта по webhook:** [@SeruendeshAl_bot](https://t.me/SeruendeshAl_bot). Отдельный процесс не нужен. Если у Railway-сервиса заданы `TELEGRAM_BOT_TOKEN` и `PUBLIC_URL`, то при старте `backend/app/telegram.py` регистрирует webhook `https://seruendesh.site/telegram/webhook` с секретным заголовком и передаёт обновления в этот же код. Бот ходит в API через localhost с `BOT_API_KEY`, поэтому лимит считается на каждого пользователя Telegram отдельно. Локальный `make bot` (polling) с тем же токеном не запустится, пока webhook активен: это один бот, а не два.

Что умеет:
- геолокация, текст или фото → 1–3 места рядом;
- «маршрут от X до Y» — маршрут между названными местами;
- под ответом у каждого места две кнопки: «🗺 Маршрут» (2GIS от точки старта) и «📍 На карте» (точка прямо в Telegram);
- отвечает на языке сообщения (ru / kk / en), на нём же подписи и кнопки;
- на голосовые сообщения вежливо просит написать текстом;
- каждое место приходит отдельной карточкой: фото места (Wikimedia Commons или сайт заведения), «почему», «что делать», часы и две кнопки;
- `/routes` и кнопка «🗺 Маршруты» — готовые маршруты от вас: символы столицы, зелёная прогулка, музеи, кофе, вечер, с ребёнком. Выбранный приходит карточками;
- `/home` и кнопка «🏠 От дома» — дом по геолокации или адресу («Кенесары 40»). Хранится в базе по хешу пользователя (не по id Telegram) и округлён до ~100 м, `/forget` стирает и его.

Тонкий клиент публичного API: геолокация, текст или фото → 1–3 места рядом. Ответы те же, что на сайте и в MCP-коннекторе. Своих данных, модели и базы у бота нет. Перенесён из бэкенда Abegerov4 (`backend/telegram_bot`) на общий API.

```bash
pip install -r bot/requirements.txt
TELEGRAM_BOT_TOKEN=... SERU_API=https://seruendesh.site python -m bot.telegram_bot
```

Лимит API считается по IP, а у всех пользователей бота он один. Задайте одинаковый секрет `BOT_API_KEY` бэкенду и `SERU_BOT_KEY` боту — тогда лимит (30 запросов и 10 фото в минуту) считается на каждого пользователя Telegram отдельно; id пользователя уходит в API только как хеш с солью. Без ключа бот работает, но делит один лимит на всех.

Или положите `TELEGRAM_BOT_TOKEN` (и при желании `SERU_API=http://localhost:8000`) в `.env` и запустите `make bot`. Один токен — один запущенный бот: вторая копия получит `Conflict: terminated by other getUpdates request`.

Приватность:
- геолокация округляется до ~100 м и живёт в памяти процесса 30 минут, `/forget` стирает её сразу;
- фото уходит в `/api/recommend/photo`: там удаляются EXIF и GPS, картинка не сохраняется;
- в логах нет chat id, координат и текста.
