# Data & RAG

Контракты: `team/README.md`, раздел 3. Из корня проекта, Python 3.11+:

```sh
pip install -r rag/requirements.txt
python data/run_pipeline.py
python rag/build_index.py
python -m unittest discover -s rag/tests
```

Перед индексацией задайте `OPENAI_API_KEY` в окружении. По умолчанию используется
`text-embedding-3-small`. `.env` автоматически не загружается. Альтернатива:
установить `sentence-transformers`, задать `RAG_EMBEDDING_PROVIDER=bge`;
будет загружена большая модель `BAAI/bge-m3`. Документы и запросы используют
одну модель из manifest индекса. После изменения датасета индекс нужно пересоздать.

```python
from rag import search, resolve_landmark, open_status, haversine_m
places = search('кофе тихо', 51.128, 71.430, 1500, categories=['cafe'])
```

Гибридный режим: гео и категории → dense top-30 + BM25 top-30 → RRF(k=60).
Близость даёт до 5% буста, наличие Wikipedia — 2% (прокси, не рейтинг).
`RAG_SEARCH_MODE=bm25` включает явный автономный режим без эмбеддингов.
Гибридный режим не маскирует отсутствие ключа или индекса под успешный dense-поиск.
Словарь русских, казахских и английских категорий помогает лексическому поиску;
тишина и другие неизвестные свойства не утверждаются.

`python data/run_pipeline.py --refresh` обновляет Overpass-кэш;
`--skip-wiki` позволяет пропустить сетевое обогащение Wikipedia.
Повторный запуск использует дисковый кэш. Выход обновляется атомарно.
Пустая или ошибочная выгрузка не заменяет предыдущую базу.
Описания без источника — ограниченные LLM-authored шаблоны по категории с
`description_source=llm_generated`; это не отдельный запрос LLM на каждую запись.
Названия, доступность, часы и координаты берутся из OSM; неизвестные значения — null.
Рейтинги отсутствуют. Дубликаты: совпадение нормализованного имени и расстояние <50 м.

`open_status` понимает дни/диапазоны дней, несколько интервалов, 24/7,
off/closed и переход через полночь. Неизвестные конструкции (PH, даты,
sunrise/sunset, комментарии и т.п.) возвращают unknown/none целиком.
Наивный datetime трактуется как время Астаны; aware datetime переводится в UTC+5.

Ориентиры ищутся по названиям базы, затем по встроенным приближённым координатам
основных ориентиров, затем в Nominatim (кэш, пауза >1 сек на сетевой запрос).
Для публичного многопользовательского сервиса замените Nominatim своим провайдером
или прокси с общим ограничением частоты; встроенный клиент предназначен для демо.

QA: `python rag/evaluate.py eval/golden_set.json`.
Считается доля запросов, у которых хотя бы один `must_include_any` входит в top-5.
Без независимого golden set порог 0.7 не считается подтверждённым.
