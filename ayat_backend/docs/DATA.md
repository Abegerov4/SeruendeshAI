# Данные: автоматический сбор POI Астаны

По условию задачи датасет собирает команда, и сбор должен быть автоматизирован. Весь процесс запускается одной командой:

```bash
cd backend
uv run python -m pipeline.cli all     # fetch → build → graph → embed → events
# или по шагам: fetch | build | graph | embed --model e5-large | events
```

Еженедельно сбор повторяет GitHub Actions ([`.github/workflows/data-refresh.yml`](../.github/workflows/data-refresh.yml)) и открывает PR с новым снимком. Снимок `data/processed/` закоммичен в репозиторий, поэтому демо не зависит от внешних API: Overpass в день разработки несколько часов отвечал ошибками 502/504.

### Что сознательно не используем
- **2GIS, Google Places, Yandex.** Их условия запрещают хранить и кэшировать данные (у 2GIS штраф до 3 млн ₽), а Google запрещает передавать данные в LLM и показывать их на не-гугловой карте. Подробнее в [RESEARCH.md](RESEARCH.md).
- **Скрейпинг 2gis.kz, Google Maps и т.п.**
- **Тексты visitastana.kz.** На сайте «все права защищены».

## Как собирается POI

1. **Категория.** Теги OSM переводятся в одну из 33 категорий ([`app/categories.py`](../backend/app/categories.py)). Для каждой категории заданы: группа, в помещении или на улице, типичное время визита, подходит ли детям, только 18+ или нет, ночная ли это активность. Закрытые места (`disused:*`, `was:*`, `opening_hours=closed`) отбрасываются. Экспонаты, нанесённые внутри зданий (`tourism=attraction` + `indoor`), тоже.
2. **Дубли.** Точка и контур одного и того же места объединяются: та же категория, похожее имя, расстояние меньше 120 м.
3. **Подписи без названий.** 282 детские площадки и часть скверов в OSM без названия. Они получают подпись по ближайшему парку (до 300 м), ЖК (до 250 м) или улице (до 200 м), например «Детская площадка (Нұржол желекжолы)». Флаг `name_auto` сохраняется.
4. **Wikidata.** Сопоставляется по тегу `wikidata`, иначе по имени (≥ 85% по нечёткому совпадению) в радиусе 300 м. Несопоставленные объекты-достопримечательности добавляются как новые POI.
5. **Wikipedia.** Описание по QID: сначала русская статья, потом английская.
6. **Overture.**
   - Фильтры: confidence ≥ 0.6; отбрасываются «стопки», когда 3 и больше мест стоят в одной точке (геокодированы в центроид); отбрасывается `historic_site` (на деле это в основном ЖК).
   - Совпадение с OSM: до 150 м и ≥ 85% по транслитерированному имени. Тогда OSM остаётся главной записью, Overture добавляет контакты.
7. **Описание**, если нет живого текста: шаблон только из фактов тегов, например «Кофейня / кафе. Кухня: кофе. Удобства: Wi-Fi, летняя веранда. Адрес: …». Без выдуманных деталей, с пометкой `description_source=template`.
8. **Популярность** (рейтингов в открытых данных нет): `0.45·log(языковые версии Wikidata) + 0.35·log(просмотры Wikipedia) + 0.2·полнота данных`.
9. **Газеттир для «Я возле…».** Названия всех POI и ЖК, вокзалы, аэропорт, стадионы, университеты из Overture и 27 вручную описанных ориентиров с алиасами на RU/KK/EN («Mega Silk Way / мега силк», «Бәйтерек», «әуежай»). Сопоставление строгое по типу объекта, чтобы кафе «Astana Arena» не стало стадионом.
10. **Пешеходный граф.** osmnx `network_type="walk"` экспортируется в массивы numpy (CSR + геометрия рёбер, 1.7 МБ). Во время работы API нужен только scipy.
11. **Эмбеддинги.** `multilingual-e5-large` (int8 ONNX) с префиксом `passage:`, float16, ~4.7 МБ. Это индексация готовой модели, а не обучение.

**Статистика текущего снимка:**
- кафе 506, рестораны 466, детские площадки 282, бары 207, парки 137, ТРЦ 90, памятники 48, мечети и храмы 30, достопримечательности 25, музеи 17, театры 18, библиотеки 18 и др.;
- часы работы есть у ~420 мест (18%). У остальных честно пишем «часы неизвестны».

## Известные ограничения данных
- **Часы работы** заполнены примерно у 1/5 мест. `check_date` почти нигде не указан, поэтому уверенность обычно «средняя».
- **Рейтингов нет:** ни один открытый источник их не даёт, поэтому `rating` всегда `null`.
- **Розетки и «тишина»** в OSM почти не отмечаются. Система прямо об этом предупреждает.
- **Описания:** живой текст из Википедии есть только у ~40 крупных достопримечательностей. У остальных описание собрано из тегов.
- **Пешеходный граф** покрывает центр, ЭКСПО и НУ. Окраины и аэропорт считаются по формуле, в ответе есть пометка.
