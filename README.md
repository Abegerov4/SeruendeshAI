Для 465 мест есть 471 ссылка на фотокандидат в публичном CDN 2GIS. **Байтов изображений нет**. `license_status: unknown`, `reuse_rights_confirmed: false`, `private_review_only: true` сохраняют отсутствие подтверждённого права повторного использования. Обложки и галереи из других источников не включены.

`null` и статус `unknown` означают отсутствие сохранённых сведений, а не отрицательный ответ. `published` означает наблюдение источника или явно помеченную производную величину; самостоятельная проверка работы заведений не проводилась. Оценки филиала и организации/сети, количество оценок и отзывов разделены. Нулевой рейтинг с нулевыми счётчиками обозначен `unrated`. Средний чек, цена ланча и полный итог приёма пищи различаются; средний чек не превращается в стоимость блюда.

Рубрики `category_names` получены из 2GIS. `primary_category`, порядок отбора, показатель и ранг популярности рассчитаны для этого отобранного набора по наблюдённым данным 2GIS; это не официальный общегородской рейтинг 2GIS. Производные поля помечены `derived_from_2gis_observations`. Исходные даты в provenance сохранены, дата экспорта их не обновляет.

В provenance оставлены публичная страница 2GIS, время наблюдения, теги и состояние утверждения. `public_capture_sha256`, если присутствует, — SHA-256 исходного захваченного публичного ответа, сохранённый как отпечаток наблюдения. Исходные ответы, локальные пути, внутренние endpoint и ключи в bundle не входят; отпечаток не означает, что исходный ответ можно восстановить из этого набора.

Файлы:

- `places.json` — 470 записей и описание 98 колонок.
- `schema.json` — JSON Schema Draft 2020-12.
- `coverage.json` — заполненность каждой колонки и общие счётчики.
- `report.json` — результаты проверок и хеши данных, схемы и покрытия.
- `manifest.json` — размеры и SHA-256 всех остальных файлов bundle; собственный хеш манифеста не включён во избежание самоссылки.
- `README.md` — описание набора.

Это только данные и документация: без скриптов, тестов, сырых HTML, локальных кэшей и публикации в активную базу.
