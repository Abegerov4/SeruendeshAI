## Границы доказательства

Настоящий FastAPI работает через TestClient в процессе pytest. Golden set использует существующие 17 backend-POI; safety/language — временные синтетические записи. Проверки реального экспорта загружают все 14 009 POI. Это keyword/template fallback, а не гибридный RAG. Модель отключена; для safety используется контролируемый ответ на границе провайдера, без замены настоящих guards и валидаторов. Внешняя трассировка также отключена или перехвачена на SDK-границе.

Здесь не измерены Recall, faithfulness реальной модели, качество RU/KK/EN, сетевая latency и работа UI. Длительность pytest не является latency API. Все 64 сценария, включая помеченные `frozen_holdout`, доступны разработчикам; это не слепая оценка. Этот каталог не является live-отчётом `eval.run_eval` для проверки готовности продукта.
